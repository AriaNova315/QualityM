# QualityM Step 8 验收记录

日期：2026-08-21  
范围：仅 DEV_PLAN Step 8（一致性导出快照与阶段综合工作簿）

## 已实现

- `ExportSnapshot` 在单个 aiosqlite 连接和显式读事务中一次加载项目、阶段、节点、审核、检查项及不符合项，启用 WAL 后计算 revision 向量和 SHA-256，再提交读事务。
- 快照 DTO 全部使用冻结 dataclass 和 tuple；Excel builder 只接收内存快照，不持有数据库连接。
- 每个有效阶段生成独立工作簿，包含审核目录、阶段质量审核工作报告、每次审核的检查单和审核报告，以及隐藏计算 Sheet。
- 同一审核实例的检查单和审核报告共用三位流水号；阶段质量报告使用独立阶段编号。
- 问题描述、严重程度和统计沿“检查单 → 单次报告 → 隐藏计算表 → 阶段报告”公式链传递，不生成第二套业务事实。
- 支持零问题、单问题、多问题、同一检查项拆分多个问题、零审核阶段、双周节点、阶段节点、未匹配节点和同日同类型节点。
- Sheet 名、文件名、业务文本和公式写入边界集中校验；工作簿设置自动计算、完整重算和强制重算。
- 目录超链接、保护区、打印区域、A4 横向/纵向页面设置和动态行高已完成。
