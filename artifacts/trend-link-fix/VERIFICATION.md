## Microsoft Excel 实测

使用 SQLite 只读连接备份真实数据库到系统临时目录，所有导出和编辑均在临时目录；没有改写真实数据库、generated/ 或 temp/ 样例。测试项目编号替换为 TREND-RELATIVE-QA，避免干扰用户已打开的工作簿。

当前数据基准：阶段数量依次为 `2, 10, 2, 3, 0, 0`，合计 `17`，严重 `2`。

1. 新生成后整体移动文件夹，单独打开趋势且不更新链接：各阶段和合计与基准一致。
2. 打开全部阶段，更新链接并全重算：与基准一致。
3. Excel 保存全部文件后，再次整体移动文件夹，旧目录不存在：打开、更新和重算仍与基准一致。
4. 对明确按名称定位的临时第一阶段工作簿，将 `_计算!D2` 的类别清空，重算后其汇总由 2 变为 1，趋势合计由 17 变为 16；恢复后再次为 17。未修改原业务记录。
5. 所有阶段关闭，仅打开趋势并更新外链：合计 17、严重 2。
6. 临时移走第一阶段源文件，再更新外链：Excel 保留缓存，仍为 17、2，没有显示假零。之后恢复该文件。

注意：源文件缺失或禁止更新时，Excel 可能保留上次缓存；缓存代表上次导出/保存值，不代表缺失源文件的最新数据。应用不承诺绕过 Excel 的链接权限与提示。

## 使用

重新导出完整包即可使用修复。旧历史导出不自动改写，以保持原始校验摘要和下载记录一致。保持同一目录和文件名；修改阶段记录后更新链接。Excel 保存文件后原始 manifest 摘要不再匹配，属于预期。
